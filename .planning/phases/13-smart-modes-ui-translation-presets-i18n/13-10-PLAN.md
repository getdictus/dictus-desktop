<objective>
Make the Apple Intelligence post-process path task-agnostic. This is the SHARED root cause behind UAT test 10 ("translation does not happen") and the truncation half of UAT test 11 ("Apple bullet output cut to 26 chars").

Root cause (from debug sessions translation-rewrite-apple-path.md + engine-persist-apple-truncation.md): `apple_intelligence.swift` ALWAYS attempts guided generation against a hardcoded `@Generable struct CleanedTranscript { let cleanedText: String }` (lines 5-9, 99-103). That schema frames EVERY task as "clean a transcript", so a "Translate to Spanish" or "Bullet Points" prompt yields near-unchanged or terse output. `provider.supports_structured_output == true` (settings.rs:617) forces the rewrite into this branch (actions.rs:213-261).

Fix: for Smart Mode (free-form) prompts, use plain free-text `session.respond(to:)` carrying the user's prompt as instructions — exactly how the working embedded LLM path behaves. Reserve/avoid the fixed CleanedTranscript schema. Also stop the word-count truncation from mangling output.

Purpose: Apple Intelligence honors arbitrary Smart Mode prompts (translate, bullets, formal, etc.).
Output: task-agnostic Swift path + actions.rs no longer truncates by word count for smart modes. Requires a macOS (Apple Silicon, macOS 26+) build to verify — hence the human-verify checkpoint.
</objective>
