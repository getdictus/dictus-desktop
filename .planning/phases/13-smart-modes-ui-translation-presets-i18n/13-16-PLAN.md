Output: A chip that captures via the backend stream on handy_keys (preserving CmdRight/CmdLeft/OptRight), keeps the existing webview path as a fallback for the Tauri implementation, feeds the side-distinct `hotkey_string` into `setSmartModeBinding`, and an idempotent `resume_all_shortcuts`.
