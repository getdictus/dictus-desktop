    ```rust
    /// Return the modifier-only "base" of a combo: the part the OS can fire on
    /// its own (every leading modifier token, dropping a trailing main key).
    /// For a modifier-only combo the base IS the whole string.
    /// Examples: "command_left+digit1" -> "command_left"; "ctrl+option+keya" -> "ctrl+option";
    ///           "command_left" -> "command_left"; "f13" -> "f13".
    fn combo_base(combo: &str) -> &str {
        let trimmed = combo.trim();
        match trimmed.rfind('+') {
            // The segment after the last '+' is the trailing main key only when the
            // token before it is a modifier chain; for our combos the leading
            // tokens are always modifiers and at most one trailing non-modifier key,
            // so the base is everything up to (not including) the last '+'.
            Some(idx) if is_modifier_token(&trimmed[..idx]) || trimmed[..idx].contains('+') => {
                &trimmed[..idx]
            }
            Some(idx) => &trimmed[..idx],
            None => trimmed, // modifier-only or single-key combo
        }
    }

    /// True when `token` (a single combo segment) names a modifier (side-distinct
    /// or compound). Used to decide whether a leading segment forms a base.
    fn is_modifier_token(token: &str) -> bool {
        let t = token.trim().to_ascii_lowercase();
        // handy_keys lowercase forms + tauri capitalized forms (compared lowercased here only).
        matches!(
            t.as_str(),
            "ctrl" | "ctrl_left" | "ctrl_right"
                | "control" | "control_left" | "control_right"
                | "option" | "option_left" | "option_right"
                | "alt" | "alt_left" | "alt_right"
                | "shift" | "shift_left" | "shift_right"
                | "command" | "command_left" | "command_right"
                | "cmd" | "super" | "super_left" | "super_right"
                | "fn" | "meta"
        )
    }
    ```

    Then extend find_conflicting_binding's closure. Keep the existing exact-equality branch first, then add the base-overlap checks. Replace the body (lines ~1135-1142) with:

    ```rust
    let candidate_base = combo_base(target);
    bindings
        .iter()
        .find(|(other_id, b)| {
            if other_id.as_str() == binding_id {
                return false;
            }
            let other = b.current_binding.trim();
            if other.is_empty() {
                return false;
            }
            // (1) exact duplicate (13-13 behavior, preserved verbatim)
            other == target
                // (2) candidate's base IS this full binding (e.g. existing "command_left",
                //     candidate "command_left+digit1") — candidate can never fire.
                || other == candidate_base
                // (3) candidate (a base key) IS the base/prefix of this binding
                //     (e.g. existing "command_left+digit1", candidate "command_left").
                || combo_base(other) == target
        })
        .map(|(other_id, _)| other_id.clone())
    ```

Two distinct full combos that merely share a modifier prefix (e.g. "command_left+digit1" vs "command_left+digit2") do NOT trigger — neither `other == candidate_base` ("command_left+digit2" != "command_left") nor `combo_base(other) == target` ("command_left" != "command_left+digit1") holds — so they remain bindable.
