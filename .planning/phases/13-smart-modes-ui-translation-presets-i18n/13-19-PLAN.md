<objective>
Close gap [G12] (UAT test 11, design decision 2026-06-08): the translation engine modal must NOT act as a second model-switcher. 13-17 added a "Use Gemma 3 4B" path that flips the single GLOBAL active post-process model — re-pointing EVERY Smart Mode at Gemma. The user rejected this UX. Translation becomes recommendation-only: ONE active model chosen via the existing main model selector; the modal/section shows an informational "Gemma 3 4B recommended for translation" note.

Two parts, ordered:
1. (Backend, Task 1) Revert 13-17's global-mutation surface: remove `set_translation_engine_to_embedded` + `restore_translation_engine_provider` (commands/llm.rs), `previous_post_process_provider_id` (settings.rs), their lib.rs registration, and regenerate bindings.ts. `set_translation_engine_choice` STAYS (it persists the enable flag).
2. (Frontend, Tasks 2-3) Convert the modal to informational recommendation-only (no switch buttons; enabling translation just persists `setTranslationEngineChoice('generic_model')`), surface the recommendation in SmartModesSection pointing to the main selector, and add/repurpose i18n keys across all 20 locales.

Purpose: restore the single-active-model mental model; the translation modal informs, it does not mutate global state.
Output: reverted backend, regenerated bindings, informational modal + section, 20-locale i18n.
</objective>
