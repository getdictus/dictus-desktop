Close the backend half of the UAT gaps so the frontend reworks (13-06, 13-07) have the commands and data they need.

This plan fixes four backend issues found in 13-UAT.md:
- GAP 4 (MAJOR): no way to clear a bound smart-mode shortcut — `change_binding` rejects empty strings, and there is no `clear`/`unbind` command. Add `clear_smart_mode_binding`.
- GAP 5 (MAJOR): the legacy `transcribe_with_post_process` binding still fires as a registered global shortcut (registered at init when `post_process_enabled`) but is invisible in the new UI. Stop registering it as a global shortcut and stop seeding it — WITHOUT breaking the deliberate `--toggle-post-process` CLI flag / SIGUSR1 action, which is a runtime action, not a persisted global shortcut.
- GAP 8a (locked decision): stop seeding all 10 modes on first run; seed only "Clean Up". Existing users keep whatever they already have (migration must not delete modes).
- GAP 8b (backend half): expose the predefined template catalogue (the current 10 modes' names + prompts + kind + target_language) via a new `smart_mode_templates` command so the frontend create-picker can source it (and recreate deleted defaults).

Purpose: deleted defaults stay recreatable, the orphan legacy global shortcut stops firing, shortcuts become clearable, and first-run is no longer cluttered.
Output: new Rust commands `clear_smart_mode_binding` + `smart_mode_templates`, a single-mode first-run seed, and removal of the `transcribe_with_post_process` binding from defaults + the three init/registration guards that referenced it.

    ```rust
    #[tauri::command]
    #[specta::specta]
    pub fn clear_smart_mode_binding(app: AppHandle, mode_id: String) -> Result<(), String> {
        let binding_id = smart_mode_binding_id(&mode_id);
        let mut settings = settings::get_settings(&app);
        // Unregister the OS-level shortcut if one is currently bound.
        if let Some(b) = settings.bindings.get(&binding_id).cloned() {
            if !b.current_binding.trim().is_empty() {
                if let Err(e) = unregister_shortcut(&app, b) {
                    error!("clear_smart_mode_binding: failed to unregister '{}': {}", binding_id, e);
                }
            }
        }
        // Remove the binding entry entirely so init_shortcuts never re-registers it.
        settings.bindings.remove(&binding_id);
        settings::write_settings(&app, settings);
        Ok(())
    }
    ```

    Register it in src-tauri/src/lib.rs in the `tauri_specta::collect_commands!`/`invoke_handler` list, right after `shortcut::set_smart_mode_binding,` (line 456): add `shortcut::clear_smart_mode_binding,`.
