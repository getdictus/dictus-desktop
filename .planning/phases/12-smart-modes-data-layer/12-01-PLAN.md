}

    2. Build a NEW `Vec<SmartMode>` separately (do not mutate `settings.smart_modes` until the end — atomic commit per RESEARCH Pitfall 5). Start by cloning `default_smart_modes()` into `new_modes`.

       - If `p.id == PRISTINE_IMPROVE_ID` but text differs (edited) → push a Rewrite `SmartMode { id: p.id.clone(), name: p.name.clone(), kind: Rewrite, prompt: p.prompt.clone(), target_language: None }` (keep edited version) AND keep Clean Up.

Determine the active id: if `settings.post_process_selected_prompt_id` is Some(sel) and a migrated mode has that id (or the pristine→Clean Up remap applies, i.e. sel == PRISTINE_IMPROVE_ID and it was replaced → use `CLEAN_UP_MODE_ID`), set `new_active_id = Some(that id)`. Then remove the `transcribe_with_post_process` entry from `settings.bindings` (retire the generic binding; combo preserved on the per-mode binding). Leave the plain `transcribe` binding untouched.
    7. Atomic commit: `settings.smart_modes = new_modes; settings.smart_mode_active_id = new_active_id; settings.settings_schema_version = CURRENT_VERSION;` Return `true`.
