    In `src-tauri/src/shortcut/mod.rs`, after `set_post_process_selected_prompt` (line 1056), add 5 commands, each `#[tauri::command] #[specta::specta]`, mirroring the prompt CRUD exactly but operating on `settings.smart_modes` / `settings.smart_mode_active_id`:

    1. `pub fn add_smart_mode(app: AppHandle, name: String, kind: settings::SmartModeKind, prompt: String, target_language: Option<settings::TargetLanguage>) -> Result<settings::SmartMode, String>`: `let id = format!("mode_{}", chrono::Utc::now().timestamp_millis());` build `SmartMode { id: id.clone(), name, kind, prompt, target_language }`, push to `settings.smart_modes`, `settings::write_settings(&app, settings)`, return the new mode.

    2. `pub fn update_smart_mode(app: AppHandle, id: String, name: String, prompt: String, target_language: Option<settings::TargetLanguage>) -> Result<(), String>`: find `settings.smart_modes.iter_mut().find(|m| m.id == id)`; if found set `name`, `prompt`, `target_language` (leave `kind` unchanged — kind is immutable post-creation), write, Ok; else `Err(format!("Smart mode with id '{}' not found", id))`.

    3. `pub fn delete_smart_mode(app: AppHandle, id: String) -> Result<(), String>`: guard `if settings.smart_modes.len() <= 1 { return Err("Cannot delete the last mode".to_string()); }`; capture original len, `settings.smart_modes.retain(|m| m.id != id)`; if len unchanged → `Err(format!("Smart mode with id '{}' not found", id))`; if `settings.smart_mode_active_id.as_ref() == Some(&id)` reassign to `settings.smart_modes.first().map(|m| m.id.clone())`; write, Ok.

    4. `pub fn set_active_smart_mode(app: AppHandle, id: String) -> Result<(), String>`: `if !settings.smart_modes.iter().any(|m| m.id == id) { return Err(format!("Smart mode with id '{}' not found", id)); }` set `settings.smart_mode_active_id = Some(id)`, write, Ok.

    5. `pub fn list_smart_modes(app: AppHandle) -> Result<Vec<settings::SmartMode>, String>`: `Ok(settings::get_settings(&app).smart_modes)`.

    All five call `settings::get_settings(&app)` to load and `settings::write_settings(&app, settings)` to persist (same as prompt CRUD). Import `SmartMode`, `SmartModeKind`, `TargetLanguage` via the existing `settings::` path or a `use` already present.

    Because these commands need a live `AppHandle`, also add a pure-logic unit test in a `#[cfg(test)]` block at the bottom of `shortcut/mod.rs` (or extend an existing one) that exercises the delete-last guard and active-reassignment as functions on a `Vec<SmartMode>` + `Option<String>` — i.e. factor the delete/reassign decision into a small testable helper `fn delete_mode_in_place(modes: &mut Vec<SmartMode>, active: &mut Option<String>, id: &str) -> Result<(), String>` and have `delete_smart_mode` call it.
