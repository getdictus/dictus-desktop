<objective>
Propagate the 25 new English i18n keys added by Plan 08-06 to all 19 sibling locale files so `bun run check:translations` exits 0 and no UI surface in any locale renders raw key paths.

Purpose: Plan 08-06 added the English source keys for the post-processing page reframe (page title, badge, subtitle, En savoir plus, selected model card, library placeholder, cloud toggle, three pillars). The project's ESLint rule `i18next/no-literal-string` plus the `check-translations.ts` parity gate require every key to exist in all 20 locale files (en + 19 siblings). Without this propagation, all 19 non-English locales would render fallback English strings (acceptable but inconsistent), and `bun run check:translations` would exit non-zero — blocking CI and any future plan that depends on a green parity check.

Output:

- All 19 sibling locale files updated with translated copies of the 25 new keys
- `bun run check:translations` exits 0 with "All 19 languages have complete translations"
- JSX placeholders (`{{count}}`) and brand names preserved verbatim
  </objective>
