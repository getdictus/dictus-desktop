THE CONFLICT (confirmed real):
  whisper-rs-sys 0.15.0 (under transcribe-rs) build.rs statically links:
    cargo:rustc-link-lib=static=whisper / ggml / ggml-base / ggml-cpu
  llama-cpp-sys-2 0.1.146 links its own ggml / ggml-base / ggml-cpu by default.
  → duplicate symbols (e.g. ggml_backend_buft_name already defined).
  Known upstream issue (llama.cpp #9267, #11303), unresolved as of May 2026.

LIBRARY:
  llama-cpp-2 = 0.1.146 (2026-04-30). Features: metal, vulkan, system-ggml, system-ggml-static.
  system-ggml sets LLAMA_USE_SYSTEM_GGML=ON (links system GGML instead of building own).

PER-PLATFORM TARGET (mirror transcribe-rs pattern at Cargo.toml:82–109):
  macOS:   features = ["metal"]
  Windows: features = ["vulkan"]
  Linux:   features = ["vulkan"]

EXISTING transcribe-rs per-platform block (Cargo.toml:82–109, the pattern to mirror):
  [target.'cfg(target_os = "macos")'.dependencies] transcribe-rs = { ..., features = ["whisper-metal"] }
  [target.'cfg(windows)'.dependencies]              transcribe-rs = { ..., features = ["whisper-vulkan", "ort-directml"] }
  [target.'cfg(target_os = "linux")'.dependencies]  transcribe-rs = { ..., features = ["whisper-vulkan"] }

EXISTING [patch.crates-io] block (Cargo.toml:111–114, the model for a ggml patch):
  [patch.crates-io]
  tauri-runtime = { git = "https://github.com/cjpais/tauri.git", branch = "handy-2.10.2" }
  tauri-runtime-wry = { git = "...", branch = "handy-2.10.2" }
  tauri-utils = { git = "...", branch = "handy-2.10.2" }

  Path 3 (Windows MSVC only, NOT primary): -C link-arg=/FORCE:MULTIPLE — not a real fix, do not rely on it.
