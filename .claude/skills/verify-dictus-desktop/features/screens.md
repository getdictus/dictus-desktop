# Dictus Desktop screen map

One stable ID per screen, `<surface>.<area>[.<sub>]`, **the same IDs as the iOS and Android screen maps** when the screen exists on the desktop: `app` (the main window), `overlay` (the recording overlay), `tray` (the tray menu), `sys` (OS screens Dictus depends on). Desktop-only screens get new IDs in the same format.

Captures are in [`../screens/`](../screens/), one `<screen-id>.png` each: tier 1 (Linux, Xvfb, debug .deb of v0.3.0 at `92ded2a`, English, light theme, isolated empty data dir), the 680x570 window only, taken with `helpers/screen.sh <screen-id>` on 2026-11-17. Re-take one when its screen changes (see `../SKILL.md`, Evidence).
